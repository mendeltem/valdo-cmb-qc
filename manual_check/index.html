Methods

Data. VALDO 2021 challenge, Task 2 (cerebral microbleeds on T2*-weighted MRI): the 57 cases used for cross-validation (sites SABRE sub-1xx, Rotterdam Scan Study sub-2xx, ALFA sub-3xx). Reference = the challenge annotation. Every case is shown with the models of the cross-validation fold that never saw it (5 folds).

Detector. Two-stage chain, the public starting model of our clinical paper. Stage 1: anisotropic 3D U-Net (inputs: inverted T2* image and its fast radial symmetry transform); its probability map is cut at 0.15, voxels are grouped into 26-connected candidates (at least 1 mm³, at most 2100 voxels, majority of the candidate not in CSF according to SynthSeg). Stage 2: a small 3D CNN scores a patch around each candidate; candidates with a score at or above the threshold are accepted; the threshold is chosen inside each cross-validation fold for the best out-of-fold F1 of its training cases (values used: ). Seed offset 0 of the selection run, recomputed on CPU on 23.11.2026 to record the decision for every candidate; training on CPU is not bit-identical, and this run has 3 false detections fewer than the stored run of the selection (cases sub-227, sub-228, sub-302; found and missed microbleeds identical; pooled lesion F1 0.623 instead of 0.616).

Findings and statistics. Clusters are 26-connected; "touch" = at least one shared voxel. TP = accepted detection touching a reference microbleed; FP = accepted detection touching none; FN = reference microbleed touched by no accepted detection. Sensitivity = reference microbleeds found / all; precision = correct detections / all detections; lesion F1 = 2·found / (2·found + false + missed), pooled over all cases. Size = diameter of the circle with the area of the largest axial cross-section; classes <2, 2–5, >5 mm (for found / missed: the size of the reference microbleed; for false detections: the size of the detection). Volume in ml = voxels × 0.25 mm³ / 1000.

Display. Model grid 0.5 × 0.5 × 1.0 mm (acquired slices 3–5 mm, so coronal and sagittal views are interpolated). Arrays turned to RAS with one transform for image, reference and detections, shown radiologically. The stored analysis image is inverted (microbleeds bright); it is turned back for display (microbleeds dark). Window per case: 1st–99.5th percentile of the brain voxels. Crops 48 × 48 mm, upsampled 3× in-plane by cubic spline and saved as lossless PNG; outlines from voxel replication (reference 2-pixel ring inside, detector 2-pixel ring outside). Thumbnails 16 × 16 mm.

Keys. O overlays, ← → finding, ↑ ↓ or wheel slice, + − zoom, Y / N answer, U next unanswered, B blind mode.
